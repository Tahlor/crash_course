1. Hash maps and sets

Mental model: trade memory for fast lookup. A set answers “have I seen x?”; a map answers “what information did I store for key x?” Average lookup/insert is O(1), with O(n) space.

Know internally: hashes map keys into buckets; collisions are handled by the implementation. You do not implement the hash table in this interview. You do need to know that dictionary lookup is average O(1), not guaranteed mathematical O(1) in every imaginable adversarial implementation.

Complete walkthrough · Two Sum

Input [2,7,11,15], target 9. Brute force tests every pair: O(n²). Instead, when reading x, the only value that can complete it is target-x.

  1. x=2, need=7. 7 not seen. Store 2→index 0.
  2. x=7, need=2. 2 is in the map at 0.
  3. Return [0,1].
def two_sum(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        need = target - x
        if need in seen:
            return [seen[need], i]
        seen[x] = i

Invariant: before processing index i, seen contains exactly the useful information from indices < i. Time O(n), space O(n).

2. Two pointers

Mental model: maintain two positions whose movement is justified by an ordering or invariant. Typical forms: opposite ends of a sorted array; slow/fast compaction; two sequences advancing independently.

Complete walkthrough · Container With Most Water

For heights [1,8,6,2,5,4,8,3,7], start at both ends. Area is min(h[L],h[R])*(R-L). The shorter wall is the bottleneck. Moving the taller wall inward cannot increase width and cannot improve the limiting height, so move the shorter wall.

  1. L=0 (1), R=8 (7): area 8. Move L.
  2. L=1 (8), R=8 (7): area 49. Move R.
  3. Continue until pointers meet; best remains 49.
def max_area(h):
    l, r = 0, len(h)-1
    best = 0
    while l < r:
        best = max(best, min(h[l], h[r]) * (r-l))
        if h[l] <= h[r]: l += 1
        else: r -= 1
    return best

Time O(n), space O(1).

3. Sliding window

Mental model: a contiguous range whose state can be updated when the right boundary grows and the left boundary shrinks. The crucial question is whether the invalid condition can be repaired by moving left only forward.

Complete walkthrough · Longest Substring Without Repeating Characters

Input abba. Keep left and the most recent index of each character.

  1. right=0, a: window [0,0], best 1; last[a]=0.
  2. right=1, b: window [0,1], best 2; last[b]=1.
  3. right=2, b repeated at 1: set left=max(left,1+1)=2. Window [2,2].
  4. right=3, a was at 0, but 0 is outside current window, so left stays 2. Window “ba”, length 2.
def longest_unique(s):
    left = 0
    last = {}
    best = 0
    for right, ch in enumerate(s):
        if ch in last:
            left = max(left, last[ch] + 1)
        last[ch] = right
        best = max(best, right-left+1)
    return best

Invariant: s[left:right+1] has no duplicate characters. Time O(n).

4. Prefix sums

Mental model: summarize everything before a position so a range or prior-state question becomes constant-time. Define P[i] as the sum of the first i values; then sum(l..r)=P[r+1]-P[l].

Complete walkthrough · Subarray Sum Equals K

Input [1,2,1,2], k=3. Let current prefix be P. A subarray ending here sums to k when an earlier prefix equals P-k.

  1. Start frequency {0:1}; P=0.
  2. Read 1: P=1; need -2 → 0 matches. Store prefix 1.
  3. Read 2: P=3; need 0 → one earlier prefix, so answer=1. Store 3.
  4. Read 1: P=4; need 1 → one match, answer=2.
  5. Read 2: P=6; need 3 → one match, answer=3.
def subarray_sum(nums, k):
    freq = {0: 1}
    prefix = ans = 0
    for x in nums:
        prefix += x
        ans += freq.get(prefix-k, 0)
        freq[prefix] = freq.get(prefix, 0) + 1
    return ans

Time O(n), space O(n). Sliding window does not generally work here if negative values are allowed.

5. Binary search — including “binary search on the answer”

Mental model: you need a monotone predicate: once some condition becomes true (or false), it stays that way. Search the boundary.

Complete walkthrough · Koko Eating Bananas

Piles [3,6,7,11], h=8. We seek the smallest integer speed k such that total hours sum(ceil(p/k)) <= 8. If speed k works, every larger speed works: monotonicity.

  1. Search k in [1,11]. mid=6 → hours 1+1+2+2=6, feasible; keep 6 and search left.
  2. [1,6], mid=3 → 1+2+3+4=10, infeasible; search right.
  3. [4,6], mid=5 → 1+2+2+3=8, feasible; search left.
  4. [4,5], mid=4 → 1+2+2+3=8, feasible. Answer 4.
def min_speed(piles, h):
    lo, hi = 1, max(piles)
    while lo < hi:
        mid = (lo + hi) // 2
        hours = sum((p + mid - 1)//mid for p in piles)
        if hours <= h: hi = mid
        else: lo = mid + 1
    return lo

Time O(n log M), where M=max pile.

6. Stack and monotonic stack

Stack: last-in-first-out. Use for nested structure, undo, DFS, parsing. Monotonic stack: keep stack values/indices increasing or decreasing so each item is pushed and popped at most once.

Complete walkthrough · Daily Temperatures

Temperatures [73,74,75,71,69,72,76,73]. Keep indices whose warmer day has not been found, with temperatures decreasing along the stack.

  1. 73 → stack [0].
  2. 74 > 73, pop 0: answer[0]=1. Push 1.
  3. 75 > 74, pop 1: answer[1]=1. Push 2.
  4. 71,69 push; then 72 pops 69 and 71, giving waits 1 and 2.
  5. 76 eventually pops 72 and 75.
def daily_temperatures(t):
    ans = [0]*len(t)
    stack = []
    for i, temp in enumerate(t):
        while stack and t[stack[-1]] < temp:
            j = stack.pop()
            ans[j] = i-j
        stack.append(i)
    return ans

Although there is a nested while-loop, each index enters and leaves once: O(n).

7. BFS and DFS

Graph representation: adjacency list is normally O(V+E) space. BFS uses a queue and explores by distance layers; DFS uses recursion or an explicit stack and follows a path deeply.

Use BFS for: shortest path when all edges have equal cost, level-order traversal, minimum number of moves, multi-source spread.
Use DFS for: reachability, connected components, cycle exploration, recursive trees, backtracking.

Complete walkthrough · Number of Islands

For every unvisited land cell, increment component count and flood-fill all connected land.

def num_islands(grid):
    rows, cols = len(grid), len(grid[0])
    seen = set()
    def dfs(r,c):
        if r<0 or r>=rows or c<0 or c>=cols: return
        if grid[r][c] != '1' or (r,c) in seen: return
        seen.add((r,c))
        dfs(r+1,c); dfs(r-1,c); dfs(r,c+1); dfs(r,c-1)
    count = 0
    for r in range(rows):
        for c in range(cols):
            if grid[r][c]=='1' and (r,c) not in seen:
                count += 1
                dfs(r,c)
    return count

Each cell is visited at most once: O(RC) time, O(RC) worst-case auxiliary space.

8. Topological sort

Use when: prerequisites, dependencies, legal execution order, DAG scheduling. A topological order exists only for a directed acyclic graph.

Kahn's algorithm: indegree counts unmet prerequisites. Start with all zero-indegree nodes. Removing a node “satisfies” one prerequisite for each outgoing neighbor. If fewer than V nodes are processed, a cycle blocked the remainder.

Complete walkthrough · Course Schedule

Courses 0..3, prerequisites [[1,0],[2,0],[3,1],[3,2]]. Interpret edge prerequisite→course: 0→1,0→2,1→3,2→3. Indegrees [0,1,1,2].

  1. Queue starts [0].
  2. Remove 0: indegree 1 and 2 become 0, enqueue both.
  3. Remove 1: indegree 3 becomes 1.
  4. Remove 2: indegree 3 becomes 0, enqueue 3.
  5. Remove 3. Processed all four ⇒ no cycle.
from collections import deque

def can_finish(n, prerequisites):
    graph = [[] for _ in range(n)]
    indeg = [0]*n
    for course, pre in prerequisites:
        graph[pre].append(course)
        indeg[course] += 1
    q = deque(i for i,d in enumerate(indeg) if d==0)
    done = 0
    while q:
        u = q.popleft(); done += 1
        for v in graph[u]:
            indeg[v] -= 1
            if indeg[v] == 0: q.append(v)
    return done == n

O(V+E).

9. Dijkstra's shortest path

Use when: weighted graph with nonnegative edge weights. If edges are all equal, BFS is simpler. Negative edges invalidate Dijkstra's greedy finalization logic.

Complete walkthrough · shortest paths

Edges: A→B cost 4, A→C cost 1, C→B cost 2, B→D cost 1, C→D cost 5.

  1. dist[A]=0, heap [(0,A)].
  2. Pop A. Relax B=4, C=1.
  3. Pop C (1). Improve B from 4 to 3; D=6.
  4. Pop B (3). Improve D to 4.
  5. A stale heap entry for B at cost 4 may still appear; skip it because it no longer equals dist[B].
  6. Final D=4 via A→C→B→D.
import heapq

def dijkstra(graph, src):
    dist = {src: 0}
    heap = [(0, src)]
    while heap:
        cost, u = heapq.heappop(heap)
        if cost != dist[u]:
            continue
        for v, w in graph[u]:
            new = cost + w
            if new < dist.get(v, float('inf')):
                dist[v] = new
                heapq.heappush(heap, (new, v))
    return dist

O((V+E) log V) in the standard heap implementation.

10. Trees and binary search trees

Mental model: recursive structure. A node's answer is often built from answers returned by its children. Decide what information each recursive call must return.

BST rule: every value in an entire left subtree must satisfy a lower/upper bound, not merely be smaller than the immediate parent. This is why checking only parent-child relationships is insufficient.

Complete walkthrough · Validate BST

Pass an allowed interval down the tree. Root starts (-∞,+∞). Left child inherits upper bound=root.val; right child inherits lower bound=root.val.

def is_valid_bst(root):
    def valid(node, low, high):
        if not node: return True
        if not (low < node.val < high): return False
        return (valid(node.left, low, node.val) and
                valid(node.right, node.val, high))
    return valid(root, float('-inf'), float('inf'))

O(n) time, O(h) call-stack space.

11. Heaps — what they actually are

Definition: a heap is a complete binary tree satisfying a local order invariant. In a min-heap every parent ≤ its children, so the minimum is at the root. It is not fully sorted.

Array representation

Store a complete tree densely in an array. For index i: parent=(i-1)//2, left=2*i+1, right=2*i+2.

values: [2, 5, 4, 9, 7, 8]
index :  0  1  2  3  4  5

        2
      /   \
     5     4
    / \   /
   9   7 8

Push: append at the end, then sift upward while smaller than parent: O(log n). Pop-min: move last item to root, remove old root, then sift downward toward the smaller child: O(log n). Peek: O(1). heapify: O(n), surprisingly better than n independent pushes.

Will you need to implement a heap? Probably not. For ordinary algorithm questions, use Python heapq. But you should be able to sketch sift-up/sift-down if asked “how does a heap work?” or if the prompt explicitly says to implement one. Python's heapq is a min-heap; use negative priorities for a simple max-heap.

Complete walkthrough · Top K Frequent Elements

Suppose counts are a:10, b:3, c:7, d:5 and k=2. Keep a min-heap of at most k pairs (count,item).

  1. Push (10,a).
  2. Push (3,b).
  3. Push (7,c) → size 3, pop smallest (3,b). Heap represents a,c.
  4. Push (5,d) → pop (5,d). Survivors are counts 7 and 10.
import heapq
from collections import Counter

def top_k(nums, k):
    heap = []
    for value, count in Counter(nums).items():
        heapq.heappush(heap, (count, value))
        if len(heap) > k:
            heapq.heappop(heap)
    return [value for count, value in heap]

With m distinct values: O(m log k), O(m+k) including the count map.

12. Union-Find / Disjoint Set Union

Use when: repeatedly merging groups and asking whether items belong to the same connected component. Core operations are find(x) and union(a,b).

Path compression: during find, point nodes directly toward the representative. Union by rank/size: attach the smaller tree below the larger. Together, amortized operations are effectively constant time: O(α(n)).

Complete walkthrough · connectivity

Edges arrive A-B, C-D, B-C. Initially every node is its own parent. Union A-B makes one group; C-D makes another; B-C joins the two roots, so A,B,C,D become one component.

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1]*n
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb: return False
        if self.size[ra] < self.size[rb]: ra, rb = rb, ra
        self.parent[rb] = ra
        self.size[ra] += self.size[rb]
        return True

13. Tries

Use when: many string keys share prefixes and you need prefix lookup, autocomplete, dictionary pruning, or character-by-character search.

Structure: each node maps next-character → child and usually stores an end-of-word flag. Search/insert costs O(L) for a word length L, independent of the number of stored words, though memory can be high.

Complete walkthrough · insert/search

Insert “cat” and “car”. Both share root→c→a; only the final branch differs t versus r.

class TrieNode:
    def __init__(self):
        self.children = {}
        self.end = False

class Trie:
    def __init__(self): self.root = TrieNode()
    def insert(self, word):
        node = self.root
        for ch in word:
            node = node.children.setdefault(ch, TrieNode())
        node.end = True
    def search(self, word):
        node = self.root
        for ch in word:
            if ch not in node.children: return False
            node = node.children[ch]
        return node.end

14. Dynamic programming

Mental model: overlapping subproblems + optimal substructure. Do not start by drawing a table. First define the state in words, then recurrence, base cases, and evaluation order.

Complete walkthrough · House Robber

Money [2,7,9,3,1]. Let dp[i] be maximum money using houses through i. At house i, either skip it and keep dp[i-1], or rob it and add nums[i] to dp[i-2].

dp[i] = max(dp[i-1], dp[i-2] + nums[i])

Values: dp0=2; dp1=max(2,7)=7; dp2=max(7,2+9)=11; dp3=max(11,7+3)=11; dp4=max(11,11+1)=12.

def rob(nums):
    prev2 = prev1 = 0
    for money in nums:
        prev2, prev1 = prev1, max(prev1, prev2 + money)
    return prev1

O(n) time, O(1) extra space.

15. Backtracking

Mental model: DFS over a decision tree. Choose → recurse → undo. Use when you must enumerate possibilities but can prune invalid partial solutions.

Complete walkthrough · Combination Sum

Candidates [2,3,6,7], target 7. At each recursion, choose a candidate at or after the current index; allowing the same index again permits reuse. Track remaining target.

def combination_sum(candidates, target):
    ans = []
    def dfs(start, remain, path):
        if remain == 0:
            ans.append(path.copy()); return
        if remain < 0: return
        for i in range(start, len(candidates)):
            path.append(candidates[i])
            dfs(i, remain-candidates[i], path)
            path.pop()
    dfs(0, target, [])
    return ans

The complexity is output/exponential in the worst case; explain pruning rather than pretending it is polynomial.

16. Sorting, sweep logic, and intervals

Sorting is often the algorithmic move: by imposing order you can make local decisions that would otherwise require all-pairs comparisons. Python sorting is O(n log n).

Complete walkthrough · Merge Intervals

Input [[1,3],[2,6],[8,10],[15,18]]. Sort by start. Keep the last merged interval.

  1. [1,3] starts result.
  2. [2,6] overlaps because 2≤3; extend end to 6.
  3. [8,10] starts after 6; append.
  4. [15,18] starts after 10; append.
def merge(intervals):
    intervals.sort()
    out = []
    for start, end in intervals:
        if not out or start > out[-1][1]:
            out.append([start,end])
        else:
            out[-1][1] = max(out[-1][1], end)
    return out

O(n log n) due to sorting.

17. Linked lists

Why review them: lower probability for this AS screen, but they teach pointer manipulation and appear inside designs such as LRU Cache. A singly linked node stores value + next; a doubly linked node adds prev.

Complete walkthrough · Reverse Linked List

For A→B→C, keep prev and cur. Save cur.next before rewiring it, or you lose the rest of the list.

def reverse(head):
    prev = None
    cur = head
    while cur:
        nxt = cur.next
        cur.next = prev
        prev = cur
        cur = nxt
    return prev

O(n) time, O(1) space.
