Amazon Applied Scientist · implementation reflexes

Practice the dangerous lines, not 40 lines of typing.

These are tiny “fill the line / spot the bug” drills for the mistakes that can sink an otherwise correct interview solution.

Use this after the lesson for a pattern. You should be able to explain why the correct line preserves the invariant—not merely recognize the syntax.

Implementation checklist

Hashing · check complement before insert when self-match is illegal.
BFS · mark seen when enqueueing.
Heap Top-K · keep K winners; the root is the easiest winner to evict.
Prefix sums · seed the empty prefix and query before incrementing current prefix count.
Binary search · know whether mid remains a candidate.
Dijkstra · stale heap entries are normal; skip them.
